# Our little scrapbook

A cozy scrapbook with three photo carousels, two love-note boxes, Sudoku, Word garden, and a hidden design studio.

Site: https://sethkail.github.io/itsjustus/

## Edit and publish

1. Open the site and choose **Edit scrapbook**.
2. Customize your photos, notes, layout, and theme.
3. Click **Save a copy** to download an HTML file containing your changes.
4. Rename the downloaded file to **index.html**.
5. Replace **index.html** in this repository on the **main** branch and commit the update.
6. GitHub Pages automatically publishes that committed version.

Editing the site saves a draft only in that browser. It does not update GitHub or change what other visitors see. Visitors can edit their own local copies but cannot change the published site without repository write access. Keep downloaded copies as backups; browser storage can be cleared or fill up.

## Hosting

GitHub Pages uses **main / (root)**. No build tools or server are needed. The `.nojekyll` file enables direct static serving. You can also double-click `index.html` to use the scrapbook offline.

This repository and site are public. Any photos or notes committed to the repository are public too. The Edit button is a local editor, not an authentication mechanism. Do not put passwords or private credentials in this file.
